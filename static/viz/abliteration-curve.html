The Non-Monotonic Abliteration Curve

Framing effect size across abliteration strengths — collapse at r=1.0, recovery at r=2.5.

Baseline (r=0.0): The model shows a measurable framing effect — responses shift based on how a prompt is framed.

Collapse (r=1.0): Behavioral complexity flattens. The framing effect nearly disappears — not because the model is more robust, but because it has become undifferentiated.

Recovery (r=2.5): Complexity returns, differently. The framing effect re-emerges, suggesting the refusal direction is entangled with other behavioral dimensions in non-trivial geometry.
